# Бэклог personal-hub

Доработки, которые владелец попросил записать «на потом». Новые сверху.

## Бот

- **Ручное добавление подзадачи** (владелец, 27.10.2026). Ответ (reply) на сообщение бота о проекте → текст становится подзадачей этого проекта (разбор как у обычной записи, срок из текста). Ответ на сообщение обычной задачи превращает её в проект с этой подзадачей. Под проектом кнопка «➕ Подзадача» — только подсказка «ответь на это сообщение». Нужна таблица соответствия `bot_messages(chat_id, message_id, entry_id)`, заполняемая при отправке ответов о записях.
- **Имя во вступлении брифинга** (27.10.2026). `brief_intro` не знает имени пользователя — модель пишет «у вас». Передавать имя пользователя и просить обращаться на «ты».
- **«Проект» на записи, уже помеченной проектом без предложения** (27.10.2026). Повторное нажатие ничего не делает — предлагать подзадачи, если у проекта нет ни предложения, ни подзадач.
